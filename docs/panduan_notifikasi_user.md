# Panduan Mengaktifkan Notifikasi Push PWA (Untuk Pengguna/Karyawan)

Dokumen ini berisi panduan langkah demi langkah bagi pengguna/karyawan untuk mengaktifkan fitur Notifikasi Push PWA aplikasi **Presensi GPS V2** pada berbagai perangkat (Android, iOS/iPhone, dan Desktop).

---

## 📱 1. Panduan untuk Android (Google Chrome / Browser Lain)

Untuk menerima notifikasi presensi secara real-time di HP Android, ikuti langkah berikut:

### Metode A: Melalui Aplikasi PWA Terinstal (Sangat Direkomendasikan)
1. Buka browser **Google Chrome** di HP Anda.
2. Akses alamat website aplikasi Presensi GPS.
3. Klik tombol menu (titik tiga) di kanan atas browser, lalu pilih **"Tambahkan ke Layar Utama"** atau **"Instal Aplikasi"** (Install App).
4. Setelah terinstal, buka aplikasi Presensi GPS dari layar utama (Home Screen) HP Anda.
5. Masuk ke halaman **Profil** (menu di kanan bawah).
6. Geser toggle **"Notifikasi Push PWA"** menjadi **ON**.
7. Jika muncul jendela konfirmasi dari sistem HP, pilih **"Allow"** atau **"Izinkan"**.

### Metode B: Melalui Browser Google Chrome Langsung
1. Buka website Presensi GPS.
2. Masuk ke halaman **Profil**.
3. Geser toggle **"Notifikasi Push PWA"** menjadi **ON**.
4. Saat browser meminta izin mengirim notifikasi, pilih **"Allow"** atau **"Izinkan"**.

---

## 🍎 2. Panduan untuk iOS / iPhone / iPad (Safari)

> **⚠️ PENTING UNTUK PENGGUNA IPHONE:** 
> Sesuai kebijakan Apple, notifikasi push web hanya akan berfungsi jika Anda menggunakan **iOS minimal versi 16.4** dan **Wajib Menambahkan Aplikasi ke Layar Utama (Add to Home Screen)**. Fitur ini tidak akan berfungsi jika Anda hanya membukanya langsung di dalam aplikasi Safari biasa.

### Langkah-langkah:
1. Buka browser bawaan **Safari** di iPhone Anda.
2. Akses alamat website aplikasi Presensi GPS.
3. Klik tombol **"Share"** (ikon kotak dengan panah ke atas di bagian bawah layar).
4. Gulir ke bawah lalu pilih menu **"Add to Home Screen"** (Tambahkan ke Layar Utama).
5. Kembali ke layar utama iPhone Anda, lalu buka aplikasi Presensi yang baru saja ditambahkan (ikon PWA).
6. Login ke akun Anda, lalu masuk ke menu **Profil**.
7. Geser toggle **"Notifikasi Push PWA"** menjadi **ON**.
8. Saat muncul permintaan izin notifikasi dari iOS, ketuk **"Allow"** (Izinkan).

---

## 💻 3. Panduan untuk Desktop / Laptop (Chrome, Edge, Firefox)

1. Buka browser favorit Anda (rekomendasi Chrome/Edge) dan akses website Presensi GPS.
2. Login dan masuk ke menu **Profil** (atau ikon dropdown profile di pojok kanan atas).
3. Temukan bagian **"Notifikasi Push PWA"** dan geser toggle ke posisi **ON**.
4. Di pojok kiri atas browser (biasanya di sebelah alamat website), akan muncul pop-up izin notifikasi. Klik tombol **"Allow"** atau **"Izinkan"**.

---

## 🔍 Solusi Masalah / Troubleshooting

### Masalah A: Tombol Toggle Otomatis Kembali Mati / Muncul Alert "Izin Diblokir"
Ini terjadi karena Anda sebelumnya pernah memilih **"Block"** (Blokir) saat browser meminta izin notifikasi. Browser mengingat keputusan ini dan tidak akan memunculkan prompt izin lagi.

#### Cara Mengatasinya:
- **Di Google Chrome (Android/Desktop):**
  1. Klik ikon **Gembok** atau **Pengaturan Situs** di sebelah kiri kolom alamat URL website.
  2. Cari bagian **Notifications / Notifikasi**.
  3. Ubah statusnya dari **Block/Blokir** menjadi **Allow/Izinkan** (atau klik Reset Izin).
  4. Segarkan/refresh halaman web, lalu coba geser kembali toggle Notifikasi di halaman profil Anda.

- **Di Safari (iOS/iPhone PWA):**
  1. Keluar dari PWA Presensi.
  2. Buka aplikasi **Settings (Pengaturan)** bawaan iPhone Anda.
  3. Masuk ke menu **Notifications (Pemberitahuan)**.
  4. Gulir ke bawah sampai Anda menemukan nama aplikasi **Presensi GPS** terinstal.
  5. Aktifkan menu **"Allow Notifications"** (Izinkan Pemberitahuan).
  6. Buka kembali aplikasi Presensi GPS PWA Anda dan aktifkan toggle pada halaman profil.

- **Di browser Firefox:**
  1. Klik ikon informasi/gembok di sebelah kiri kolom alamat URL.
  2. Klik tanda silang (X) di sebelah tulisan "Blocked" pada bagian izin notifikasi.
  3. Refresh halaman dan coba aktifkan kembali toggle.
